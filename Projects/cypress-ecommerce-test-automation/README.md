# E-commerce QA Automation

## 1. Project Overview

This project focuses on developing an automated testing framework using Cypress to validate the functionality of an e-commerce web application.

The project aims to demonstrate software testing principles, test case design, UI automation, API testing, and continuous integration through GitHub Actions.

The application under test is SauceDemo, a sample e-commerce platform that provides functionality for user authentication, product browsing, shopping cart management, and checkout.

## 2. Project Objectives

Develop an organized and maintainable Cypress E2E testing framework.

Apply software testing principles and test design techniques.

Automate functional and regression test scenarios.

Validate positive and negative application behaviours.

Explore API testing and network interception using Cypress.

Integrate automated tests into a CI/CD pipeline using GitHub Actions.

Generate test execution reports and maintain test evidence.

## 3. Installation and Setup

```bash
npm install         // install dependencies
npx cypress open    // open cypress test runner
```
