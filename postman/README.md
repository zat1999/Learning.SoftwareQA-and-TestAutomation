# Postman Playground and Projects
This directory contains some sample projects and tutorials for testing the Postman API testing/automation. 

## Sample Projects
- Hotel Booking API AUtomation
    - Simulate hotel booking application.
    - Using API from [Hotel Booking Site](https://restful-booker.herokuapp.com/apidoc/index.html)
- Simple Book API
    - Test Rest API : GET, POST, PUT, PATCH and DELETE.
    - Using API from [Simple-Books](https://simple-books-api.click)
